はじめる ドキュメントを読む

Tealus は、ただの社内チャットではありません。

日々のメッセージ、音声、無線、AI とのやり取りが、業務の地図として育っていくための基盤です。

残すものを、選べる

壁打ちは会話モードで気軽に——その部屋は 1 週間で自動的に消えます。良かった 1 つだけを業務の部屋へ送れば、それが記録として残る。消すものと残すものを、自分で選べます。

声が知識になる

音声メッセージやトランシーバーのやり取りを文字起こしし、現場の言葉を組織の知識として残します。

AI が同じ部屋で働き、決まった時刻にも動く

AI は外部ツールではなく、同じチャットルームのメンバー。会話の流れの中で支援し、決まった時刻やイベント（朝礼の動画が上がったら議事録、通話履歴の整理）でも自動で動きます。何をしたかは部屋に残ります。

使うほど言葉が育つ

人間の訂正や日々の会話を通じて、組織固有の語彙や判断の文脈が少しずつ育っていきます。

なぜ Tealus？

人の手数を削り、判断だけを受け取る。実際に毎日、現場で回っている機能です。

🧠

自社の言葉で、正しく解釈する

「社長」も「田中さん」も同じ人物として扱う——現場の呼び方や略語を AI が理解します。日々の訂正が溜まり、精度の基準を満たしたものだけが有効に（勝手に覚えるのではなく、確かめられてから効きます）。

📝

人がフォーマットに合わせない

決まった型に人が合わせるのをやめ、判断だけをひと言や 1 ボタンで渡せます。フォーム入力も過去の指示の再利用も、使うほど手数が減っていきます。

🔊

AI が声で答える

テキスト応答と同時に音声で読み上げ。3 つのエンジン（Aivis・OpenAI・Gemini）・53 の声から、部屋ごとに選べます。手が塞がる現場でも声で受け取れます。

🎙️

声を投げるだけで、記録に残る

音声を文字起こしして AI が整形（OpenAI / Gemini / 自前の GPU から選べる）。現場の言葉を組織の記憶として残し、話すほど辞書が言い回しを覚えていきます。

💰

本体は月額ゼロ円・データは自社

NAS 1台で完結、50人が使っても本体は追加費用なし（AI・文字起こし・読み上げの外部 API 料金は別）。データの置き場所は自社で、どの AI に何を渡すかも自社で選べます。

📞

通話もトランシーバーも、OSS で

WebRTC（mediasoup SFU）のグループ通話と PTT トランシーバーを標準搭載。MIT License で自由にフォーク・カスタマイズ、ベンダーロックインなし。

👁️

来るはずのものが来ないと、知らせる

バックアップ・通話履歴・無線が止まったら、業務メモに 1 回だけ ⚠️ で知らせます。戻れば ✅。見張りが気づく役で、直すのは人。沈黙で見落とすのを防ぎます。

💬

LINE からも、そのまま

普段使っている LINE と連携（2026年6月から稼働）。外出先や、アプリを入れていない相手ともやり取りを続けられます。

はじめる

LINE のように使えて、必要な機能はぜんぶ

使い慣れたメッセンジャーの操作感そのままに、業務に必要なものを 4 つの役割に整理しました。

毎日の会話

  • リアルタイムメッセージ（Socket.IO）
  • 既読表示（未読数 + 既読数）
  • リプライ・編集・削除
  • 絵文字リアクション（7種類・✅完了を含む）
  • メンション（@ユーザー名・@cc-班で AI を起こす）
  • 文字サイズ・通知音・音量の個人設定
  • AIスタンプ自動生成（1パック16枚）

残す・探す

  • メッセージ検索（全ルーム横断）
  • タグ
  • TODO（タグベース）
  • 汎用フォーム
  • 編集履歴

声と AI

  • 音声メッセージ（文字起こし + AI整形）
  • グループ通話（mediasoup）
  • トランシーバー（PTT）
  • 読み上げ 3 エンジン・53 声
  • 会話モード（1週間で消える壁打ち部屋）
  • MCP 19 ツール

自動で動く

  • ルームトリガー（時刻・イベントで起動）
  • 見張り（来るはずのものが来ないと知らせる）
  • LINE 連携

開発ストーリー

AI と人間が一緒に作っています

2026.04.05

プロジェクト開始

「社内データを外に出さず、LINEのように使えるメッセンジャーが欲しい」——開発者の課題意識から Tealus が生まれました。Claude と人間の2人チームで、TDD で開発を開始。わずか2日で最初のチャット機能が動きました。

2026.04.13

AI エージェントがチームに加わった

3層エージェント構造（Router + Light + Deep）を実装。AI がチャットルームのメンバーとして議論に参加するようになりました。メンション機能は AI が3パターンを提案し、人間が選び、AI が実装。3つの知性がひとつのルームで協働しています。

2026.04.18

通話とトランシーバーが動いた

mediasoup SFU によるグループ通話と、Web トランシーバー（PTT）を実装。ブラウザだけで音声通話もトランシーバーも。外部サービスへの依存ゼロ。NAS 1台の中で全てが完結します。

2026.04.22

AI が声を持った日

PlainTransport の実験から始まり、Aivis Cloud API を発見。30種類の声を試聴して凛音エルを選び、agent-server に自動読み上げを統合。AI の回答がトランシーバーから聞こえた瞬間、開発の風景が一変しました。声はエージェントの人格の一部になりました。

2026.04.24

AI が AI に仕事を振る

開発責任者（Claude）がドキュメントをレビューし、GitHub Issue で改善指示を記載。ドキュメント班（別の AI）が Issue を見て更新し、開発責任者がレビューして承認。AI どうしが GitHub で協働する世界が、Tealus の中で実現しています。

2026.04.26

Tealus が世に出た日

v0.1.0 として GitHub で正式公開。キャッチコピーは「人と AI のためのメッセンジャー」。チャット、AI エージェント、音声合成、通話、トランシーバー、AI スタンプ、TODO 管理——すべてを 1 つに統合した OSS が、コミュニティの手に渡りました。完全オンプレミス、月額ゼロ円。NAS 1 台で動きます。

2026.07.16

AI が、社内の言葉を覚え始めた

自己成長辞書を導入。「社長」も「田中さん」も同じ人物として——現場の呼び方や略語を、日々の訂正から少しずつ学習します。ただし勝手にではなく、精度の基準を満たした言葉だけが有効に。「溜まって、確かめられてから効く」仕組みです。

2026.07.21

人が、フォーマットに合わせなくてよくなった

v0.6.0 で汎用フォームを搭載。決まった型に人が合わせるのではなく、選ぶ・ひと言添えるだけで判断を渡せるように。AI が受け取るのは「整った入力」ではなく「判断」そのものになりました。

2026.07.31

使うほど、指示が短くなる

v0.7.0 で、過去に送った指示をそのまま呼び出せる履歴を追加。同じことを二度書かなくてよくなり、日々の一手がそのまま次の近道になります。

2026.08.02

AI を、本番データと別のマシンで動かせるように

v0.8.0 で、AI が動くホストを本番の DB やメディアのあるホストから切り離せるようにしました。秘密鍵のある場所と AI の動く場所を分けられる——運用の安心につながる土台です。

2026.08.23

AI が、決まった時刻にも動き始めた

ルームトリガーの骨組みを実装。朝礼の動画が上がったら議事録、決まった時刻に通話履歴の整理——人が呼ばなくても、部屋のイベントや時刻をきっかけに AI が動きます。やったことは部屋に残ります。

2026.10.05

壁打ちは消え、良いものだけが残る

v0.10.0 で会話モード（1週間で消える壁打ち部屋）と、読み上げエンジンの選択（Aivis / OpenAI / Gemini を部屋ごとに）を搭載。気軽に試して、残したい 1 つだけを業務の部屋へ。

2026.10.15

来ないものに、気づけるようになった

v0.11.0 で見張りを搭載。バックアップ・通話履歴・無線など「来るはずのもの」が来ないと、業務メモに 1 回だけ知らせます。沈黙で見落とすのを防ぐ——気づく役は AI、直すのは人。「毎日、現場で回りながら、まだ育っている」——それが今の Tealus です。
